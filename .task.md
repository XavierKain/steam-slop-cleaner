# Steam Next Fest Slop Cleaner

## Goal
A React web app that lets users browse Steam Next Fest games with filters to hide AI-generated content and asset flips. "Clean discovery" for indie games.

## Core Features (MVP — 1 night)
1. **Fetch games** from SteamDB/Steam Store API (Next Fest or Steam app list with tags)
   - Use Steam Store API: `https://store.steampowered.com/api/featuredcategories/`
   - Or SteamDB via web scraping/public endpoints
   - Filter by: "AI Generated Content" tag (tag ID: 493), and other slop signals
2. **Filter panel** (sidebar):
   - Toggle: Hide AI-generated content (Steam's official "AI Generated Content" tag)
   - Toggle: Hide "Asset Flip" (tag: "Asset Flip")
   - Filter by: minimum reviews, minimum rating %
   - Filter by: free / paid / demo available
3. **Game cards grid**: cover image, title, dev name, review score, tags, link to Steam page
4. **Clean UX**: fast, no bloat, mobile-responsive

## Tech Stack
- React + TypeScript + Vite
- TailwindCSS for styling
- React Query for data fetching
- Steam Store API (public, no auth required)
- Deploy-ready on Vercel (static)

## Steam API endpoints to use
- Featured: `https://store.steampowered.com/api/featuredcategories/?cc=us&l=en`
- App details: `https://store.steampowered.com/api/appdetails?appids=XXX`
- Search/tags: `https://store.steampowered.com/api/storeSearch/?term=next+fest&cc=us`
- Tag IDs: AI Generated Content = 493, Asset Flip = 1773
